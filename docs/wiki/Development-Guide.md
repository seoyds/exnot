# Development Guide

[← Home](Home.md)

## Prerequisites

- Python 3.12+
- Docker & Docker Compose
- PostgreSQL 16 (or use Docker)
- Redis 7 (or use Docker)
- An OpenRouter API key (for AI features)

## Local Setup

### 1. Clone and Install

```bash
git clone <repo-url>
cd exnot

# Create virtual environment
python -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -e ".[dev]"
```

### 2. Configure Environment

```bash
cp .env.example .env
# Edit .env with your settings (see Configuration Guide)
```

Minimum required variables:
```bash
DATABASE_URL=postgresql+asyncpg://exnot:password@localhost:5432/exnot
DATABASE_URL_SYNC=postgresql+psycopg2://exnot:password@localhost:5432/exnot
REDIS_URL=redis://localhost:6379/0
OPENROUTER_API_KEY=sk-or-v1-your-key
SECRET_KEY=your-secret-key
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=changeme
```

### 3. Start Infrastructure

```bash
# Start PostgreSQL + Redis (+ MinIO if needed)
docker compose up db redis -d

# Or run everything except the app:
docker compose up db redis minio -d
```

### 4. Run Database Migrations

```bash
alembic upgrade head
```

### 5. Start the Application

```bash
# Web server (with hot reload)
uvicorn exnot.api.app:app --host 0.0.0.0 --port 8000 --reload

# In separate terminals:
# Celery worker
celery -A exnot.workers.celery_app worker -l info -c 4 -Q default,scraping,notifications

# Celery beat (for scheduled tasks)
celery -A exnot.workers.celery_app beat -l info
```

### 6. Access the Application

- **Dashboard**: http://localhost:8000/dashboard
- **API docs**: http://localhost:8000/api/docs
- **Flower**: http://localhost:5555 (if running)

## Database Migrations

```bash
# Apply all pending migrations
alembic upgrade head

# Create a new migration from model changes
alembic revision --autogenerate -m "add column to normalized_fees"

# Check current migration version
alembic current

# Downgrade one step
alembic downgrade -1

# View migration history
alembic history
```

**Convention**: Always review autogenerated migrations before applying — check for:
- Unwanted table drops
- Missing index creation
- Incorrect column types for JSONB fields

## Project Conventions

### Code Organization

- **Repository pattern**: All DB access through `db/repositories.py`
- **Async throughout**: Use `async`/`await` for I/O operations
- **Type hints**: All function signatures should have type annotations
- **Pydantic models**: Used for API schemas, AI output types, and configuration

### Naming Conventions

- **Exchange codes**: `UPPERCASE_WITH_UNDERSCORES` (e.g., `CBOE_BZX`)
- **Enum values**: `UPPER_SNAKE_CASE`
- **File names**: `lower_snake_case.py`
- **Test files**: `test_<module>.py`

### Adding a New Exchange

1. Create YAML file in `src/exnot/exchanges/definitions/`
2. Create prompt file in `src/exnot/ai/prompts/` (optional)
3. Register prompt in `src/exnot/ai/prompts/registry.py`
4. Restart app (auto-seeds to DB)
5. Run discovery: `POST /api/v1/admin/discover/{code}`
6. Trigger scrape: `POST /api/v1/admin/scrape/{code}`

### Adding a New API Endpoint

1. Add route in appropriate file under `src/exnot/api/routes/`
2. Add Pydantic schemas in `src/exnot/api/schemas.py`
3. Add repository methods in `src/exnot/db/repositories.py` if needed
4. Register router in `src/exnot/api/app.py` if new file

### Adding a New Celery Task

1. Define task in `src/exnot/workers/tasks.py`
2. Add queue routing in `src/exnot/workers/celery_app.py`
3. Add beat schedule in `src/exnot/workers/schedules.py` if periodic
4. Use `asyncio.run()` bridge for async operations

## Debugging

### Common Issues

**AI extraction returns no fees**:
1. Check the exchange prompt in `ai/prompts/` — does it match the document structure?
2. Look at `AgentEvent` records in the monitor for the raw AI response
3. Try a different model: `AI_MODEL_FEE_EXTRACTION=anthropic/claude-3.5-sonnet`

**Scrape hangs or times out**:
1. Check if the exchange requires `scraper_type: BROWSER`
2. Verify the URL is accessible: `curl -I <fee_schedule_url>`
3. Check Celery worker logs for task timeout messages

**Profile extraction gives wrong results**:
1. Delete the `ExchangeProfile` record for the exchange
2. Re-run the pipeline — it will do AI extraction and rebuild the profile
3. Check `match_ratio` — below 0.70 means the profile stays in LEARNING mode

### Useful Queries

```sql
-- Latest snapshot per exchange
SELECT e.code, s.version, s.ai_confidence, s.ai_cost_usd, s.scraped_at
FROM exchanges e
JOIN fee_schedule_snapshots s ON s.exchange_id = e.id
WHERE s.version = (SELECT MAX(version) FROM fee_schedule_snapshots WHERE exchange_id = e.id);

-- Recent fee changes
SELECT e.code, fc.change_type, fc.participant_type, fc.fee_type,
       fc.old_amount_cents, fc.new_amount_cents, fc.detected_at
FROM fee_changes fc
JOIN exchanges e ON e.id = fc.exchange_id
ORDER BY fc.detected_at DESC LIMIT 20;

-- AI costs by exchange
SELECT e.code, COUNT(*) as runs,
       SUM(ar.total_cost_usd) as total_cost,
       AVG(ar.total_cost_usd) as avg_cost
FROM agent_runs ar
JOIN exchanges e ON e.id = ar.exchange_id
GROUP BY e.code ORDER BY total_cost DESC;
```
